# VocalFocus-Project
'VocalFocus' is a desktop application that captures live audio and **focuses on a selected (enrolled) speaker** by separating voices and keeping the target speaker’s speech as the final output. It is designed to help isolate one person’s voice from a mixed recording (e.g., multiple speakers in the same room), then save a cleaned/purified audio file.

## Key Features
- **Speaker Enrollment:** Create a profile using a short voice sample.
- **Target Speaker Focus:** Choose which enrolled speaker to keep.
- **Live Audio Capture:** Record a mixture from your microphone/input device.
- **Voice Purification:** Separate sources and keep the target speaker output.
- **Organized Outputs:** Saves recordings and purified results into dedicated folders.

**Note:** To run the project correctly, please check the **`requirements.txt`** file and install all dependencies listed there.
